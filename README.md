# AILearn

My personal GitHub for understanding AI from the ground up
\*this is actually for Deep Learning :v

### Requirements

- This project can only be run on **LINUX**
    - Due to, TensorFlow Version
    - Due to, Unix Makefile\*
- CMake (4.2)

\*Using CMake Visual Studio generator it is possible to run on Windows but it has not been tested yet

### Usage

**Run the CPP**

```bash
cd ./cpp
sudo chmod 777 bld
sudo chmod 777 bnr
sudo chmod 777 run
./bnr
```

`bnr`: Build and Run \
`bld`: Build \
`run`: Run

**Run the Python**

1. Check the `python` folder
2. `pip install -r requirements.txt`
3. Run _Jupyter Notebook_ as usual
